Connect to Claude

Access your golf data, coaching plans, and course strategy through natural conversation — powered by 73 live tools.

Add Looper Golf to Claude

The Looper app generates a personal Connection URL with your authentication token built in. Copy it and paste it into Claude.

1
Open the Looper app → tap AI Assistants → tap Copy URL. Your personal Connection URL includes your authentication token — no separate login required.
2
Claude.ai (web): Settings → Integrations → Add custom connector → paste the URL → Save
3
Claude iOS / Android: Settings → Integrations → Add → paste the URL
4
Start asking questions — "What's my average 7-iron carry?" or "Plan a round strategy for me."
Token expiry: Connection URLs are valid for 1 year. If Claude stops responding, return to AI Assistants in the Looper app to generate a fresh URL.

Try these once connected

  • "How far does my 7-iron carry and where do I rank vs PGA Tour?"
  • "What are my active swing faults and what drills fix them?"
  • "Give me a full strategy for my next round — I'm playing Drottningholm."
  • "I'm 153 metres out with a headwind and a bunker left — what do I hit?"

Claude Desktop & Claude Code

Get your Connection URL from the Looper app, then add it to your Claude config file.

1
Open the Looper app → tap AI Assistants → tap Copy URL.
2
Claude Desktop: open claude_desktop_config.json and add:
{ "mcpServers": { "looper-golf": { "url": "<paste your Connection URL here>" } } }
3
Claude Code: run /mcp add looper-golf <your URL> or paste the JSON above into ~/.claude/settings.json
4
Restart Claude Desktop and try: "Design a practice plan to fix my slice."
Token expiry: Connection URLs are valid for 1 year. If Claude stops responding, return to AI Assistants in the Looper app to generate a fresh URL.
